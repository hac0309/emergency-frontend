🚽 나 지금 급해
공공화장실 찾기 & 후기 공유 웹 서비스
📅 진행 기간: 2024.06.21 ~ 2024.07.18






📌 프로젝트 소개
**"나 지금 급해"**는 공공화장실 API와 카카오 지도 API를 활용하여
위치 기반 화장실 탐색, 후기 및 평점 작성, 포인트 적립 및 포인트 샵 이용 기능을 제공하는 웹 서비스입니다.

🧩 주요 기능
✅ 카카오 지도 기반 주변 공공 화장실 탐색

✅ 후기 작성 시 포인트 지급 및 적립

✅ 적립된 포인트로 포인트 샵에서 아이템 구매

✅ 장바구니, 아이템 상세 페이지, 결제 시스템 구현

✅ 포트원 API를 연동한 실시간 결제 처리

🛠️ 기술 스택
Frontend: React, Redux, HTML5, CSS3

Backend: Node.js, Express, MongoDB

외부 API: 공공화장실 API, Kakao 지도 API, PortOne(구 아임포트)

🖥️ 화면 구성
웹 해상도: 1440px x 1024px

반응형: max-width: 767px 이하 대응
